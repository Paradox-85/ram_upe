Answer:
Key points from the UPE interviews — and the items that interviewees flagged as most valuable to focus on — cluster around consistency, automation, governance, templates/standards, onboarding/access, CDE interoperability, and tooling for reuse of knowledge. Summarised:

1. Make project setup consistent and simple
- Need a “golden path” or “perfect project” example and clear description of processes, checks and routines so projects are set up the same way and basics are fixed. Interviewees want a sample project that exemplifies expected model delivery and delivery requirements (incl. machine-readable delivery plan) so everyone knows “what to deliver, when, by whom” [Document: UPE Interviews (source 1)].

2. Automate onboarding and repetitive setup tasks
- Automated onboarding routines and tools (Power Automate / Project Hub / SharePoint integrations) to shorten lead times and reduce manual steps (current legacy flows: MS Form → SP list → Power Automate) were repeatedly mentioned as priorities [Document: UPE Interviews (source 2), (source 5)].
- Building an automation standard for citizen developers and surfacing jobs (e.g., BIMbot jobs) were called out as practical ways to reduce manual work [Document: UPE Interviews (source 2), (source 5)].

3. Standardise templates, naming, classification and digital requirements
- Clear, enforced templates and naming conventions, classification systems (RDS/object IDs), and data standards are needed so client templates don’t unintentionally override Ramboll templates and property data isn’t added manually during exports [Document: UPE Interviews (source 2), (source 4), (source 5)].
- Machine-readable artifacts (list of delivery packages, client requirements, project model) were requested to reduce ambiguity [Document: UPE Interviews (source 2)].

4. Improve governance and make standards easy to use
- Governance, approvals and access lists (incl. JV systems) need clearer, faster processes; people resist procedures that add effort, so lowering the bar and making standards built-in is important [Document: UPE Interviews (source 2), (source 4)].
- Interviewees ask for an approval process that shortens lead time and better tools to implement procedures rather than only documenting them [Document: UPE Interviews (source 2), (source 4)].

5. Access management and project administration during lifecycle
- Managing user access, approvals (PM / design manager), and ongoing admin are pain points; interviewees want easier ways to grant access and manage project org charts, access lists and confidential projects [Document: UPE Interviews (source 5), (source 2)].

6. CDE choice, interoperability and connectivity
- Projects often span multiple CDEs; respondents want guidance on choosing the correct CDE, distributed setups, and improved connectivity between CDEs to avoid missed opportunities and reduce time-consuming manual syncing [Document: UPE Interviews (source 2), (source 3), (source 4)].
- Specific platform actions described (Trimble Connect, Quadri, Teams) show many manual steps (folder/templates, federated models, syncs, CRS/orthophoto import) that could be automated or standardised [Document: UPE Interviews (source 5)].

7. Reduce manual property and IFC conversion work
- Setting up property sets (from Excel templates), populating them into Quadri/Civil3D/Tekla, and configuring Quadri→IFC conversion rules (to ensure expected properties) is time-consuming and error-prone — a clear automation/standardisation target [Document: UPE Interviews (source 5)].

8. Surface and reuse institutional knowledge with AI/agents and sandboxes
- Interest in agents/LLMs to index large technical handbooks, surface lessons learned, let CAD agents author/perform diffs/reviews, and use local open-weight models in low-trust environments to capture Ramboll engineering knowledge without excessive LLM costs [Document: UPE Interviews (source 2)].

Most valuable focus areas (prioritised):
1. Create the “golden path” sample project, delivery requirements and machine-readable delivery plan to standardise expectations (high impact on consistency) [source 1].
2. Automate onboarding and recurring setup flows (Project Hub, Power Automate, templates) to cut lead times and manual errors [source 2, source 5].
3. Standardise templates, naming conventions, classification and property set handling (including IFC conversion rules) to eliminate repetitive manual property work [source 4, source 5].
4. Improve governance and embedded enforcement (approvals, access lists, JV handling) and reduce friction so people adopt standards [source 2, source 4].
5. Address CDE interoperability and syncing (distributed CDE guidance and tooling) to reduce multi-platform overhead [source 2, source 3].
6. Explore agent/ML tooling for indexing large reference docs and surfacing lessons-learned while controlling costs and trust boundaries [source 2].
